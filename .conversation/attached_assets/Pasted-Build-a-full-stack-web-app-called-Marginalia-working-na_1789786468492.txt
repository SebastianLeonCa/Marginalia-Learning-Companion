Build a full-stack web app called "Marginalia" (working name): a personalized learning companion for people who read dense material (PhD/higher-ed students, heavy readers). The user uploads one or more PDFs, reads them in an immersive distraction-free reader, selects any passage to get a concise explanation and REAL references for further reading, and the app automatically turns the material into a gamified quiz and single-player minigames with points, streaks and powerups. No camera or eye tracking.

TECH: React + TypeScript frontend, Node/Express backend, PostgreSQL (use whatever is fastest on Replit). Simple email/password auth (or Replit Auth if faster). All LLM calls happen on the server. If you need an API key, ask me instead of hardcoding it.

BUILD ORDER: make each step work end to end before starting the next one.
1) Auth + Home + PDF upload  2) Study Set hub + Reader  3) Quiz  4) Minigames  5) Progress

CORE USER FLOW
Login -> Home -> upload one or several PDFs -> a "Study Set" is created -> Study Set hub -> choose Read / Quiz / Minigames / Notes.

PAGES
1. Login / sign up.
2. Home (landing after login): a big drag-and-drop upload zone at the top ("Drop one or more PDFs to start learning"), accepting up to 5 PDFs per upload. Below it: the user's previous Study Sets (title, date, number of documents and notes, best score), a "Continue reading" shortcut, and a "Confusion points" section with passages the user flagged. Show a friendly error for scanned PDFs without extractable text.
3. Study Set hub: shows the documents in the set and four big illustrated cards: Read, Quiz, Minigames, Notes & Progress. Generation runs in the background right after upload: the user can open the Reader immediately, and Quiz/Minigames unlock as soon as they are ready (show a status chip per feature with a progress indicator). For long documents, split the text into sections and sample the most information-dense ones to keep generation fast.
4. Reader (per document, with tabs to switch between documents in the set):
   - Render the PDF in the browser with pdf.js, with a real selectable text layer, page navigation and zoom.
   - On text selection, show a floating toolbar: "Explain", "Find references", "Flag as confusing", "Save note".
   - Explain: send the passage plus surrounding context to the LLM and return a 2-3 sentence plain-language explanation.
   - Find references: the LLM extracts the key concepts and produces 2-3 search queries; the backend queries free academic APIs (Semantic Scholar and/or OpenAlex, plus arXiv) and returns 3-5 REAL papers (title, authors, year, link). The LLM must never invent citations: every reference must come from an API result.
   - Results appear in a side panel that never covers the text.
   - Save note: stores passage, page, explanation, references and an optional personal comment.
   - "End session" generates a concise recap (key points + all references collected) and saves it.
5. Quiz (from the whole Study Set): the LLM generates 10 multiple-choice questions (4 options, one correct, short explanation, difficulty, source document and page), prioritizing passages flagged as confusing. Strict JSON output.
   - One question at a time, 20-second countdown. Score = 100 base + time bonus (up to 50). Streak multiplier: 3 in a row = x1.5, 5 in a row = x2; a wrong answer resets it.
   - Powerups: each game starts with 1 of each, and the player earns 1 random extra powerup every 5-answer streak. One powerup per question. Freeze Time (pauses the timer 10s), Double Down (next question worth double), 50/50 (removes two wrong options), Second Chance (retry once for half points), Hint (shows a source snippet, costs 25 points).
   - End screen: score, accuracy, best streak, missed questions with explanations and a "Review in reader" link that opens the source page.
6. Minigames (single-player, generated from the uploaded PDFs, each with a timer, points and streak bonuses, and the same visual style):
   - Match Pairs: memory-style card grid where the player matches terms with their definitions.
   - Fill the Blank: a key sentence from the text with a missing term; pick from a word bank.
   - True or False Blitz: rapid-fire statements about the material, swipe or tap, streak bonuses.
   - Sequence Sort: drag steps of a process or events of a timeline into the correct order.
   Freeze Time and Double Down powerups also work in any timed minigame. Generate the content for every minigame as strict JSON, cache it in the database, and let the user regenerate it.
7. Notes & Progress: all saved notes and recaps for the set, total points and accuracy over time (small chart), best scores per game, and "Topics to review" = concepts the user missed most. Missed concepts must appear more often in the next quiz and minigames for that set.

DATA: users, study_sets, documents (extracted text per page), sessions, notes (passage, page, explanation, references JSON, flagged, comment), quiz_questions, minigame_content (type, JSON), game_results (game type, score, accuracy, missed concepts), powerup_inventory, concepts (with miss counts). PDFs are private to each user and never shared.

DESIGN: Warm, hand-illustrated, folk-art inspired style (reference: the Behance project "Ukrainian food and cuisine illustration"). Cream paper-textured background, rich saturated accents (beet red, sunflower yellow, leaf green, deep blue), soft thick outlines, decorative illustrated motifs (fruits, vegetables, plants, ornamental borders, embroidery-like patterns), rounded cards, a friendly serif for headings and a clean, very readable font for body text. Use illustrations generously on login, Home, the Study Set hub, games and empty states, and celebrate streaks with confetti in the app's palette. Keep the Reader itself calm: paper-colored background, generous margins, minimal interface chrome, so the user can concentrate.
